LinkUp modifications to the Android JNI wrapper (2026-10-16): serialized
native handles, removed unused UAPI socket and debug logging/signal hook,
returned public statistics only, and built against current upstream WireGuard
and Go. The WireGuard protocol and cryptographic engine are not modified.

The old Go JNI binary and the independent wg / wg-quick executables inside
the Maven AAR are excluded. LinkUp uses only the Go backend. AndroidX
annotation/collection notices are covered by their separate runtime licences.

Unlike the upstream Android make recipe, this build uses unmodified Go
runtime clock semantics. This prototype stops at screen lock/background;
it does not promise a persistent VPN while the phone is sleeping.

To rebuild: node app/scripts/build-wireguard.mjs
The recipe verifies downloads and Go module checksums. See provenance.json.
